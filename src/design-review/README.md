# Shared local component review

- `registry.ts` lists the components shown on the one `Design Review / Overview` page. Each registration declares its own reference and proposal directories, views, visual comparison, Figma link, and service ID. Duplicate IDs or directories are rejected.
- CTAButton retains its frozen approved copy in `reference/`, its isolated `proposal/`, and its existing Figma MCP review record. Its application component and approval data are unchanged.
- ProductLogo has separate copies and SVG assets in `product-logo/reference/` and `product-logo/proposal/`. `reference/baseline.json` records a pilot baseline, not a corporate approval. `proposal/review.json` records the initial Figma MCP inspection. Its exact Figma component set is node `112:6027`.
- Future ProductLogo MCP reviews should update only `product-logo/proposal/` and its review record. Current and the application component remain untouched until explicit approval. Its local service is read-only: it reports differences, but offers no browser scan, preparation, or apply endpoint.
- KeyHighlights has isolated snapshots and approved Figma badge SVGs in `key-highlights/reference/` and `key-highlights/proposal/`. Its reference is an initial pilot baseline, not a corporate approval. The Metrics instance is node `313:34148`; the main component is `308:30455`; design and motion guidance is in documentation frame `313:33806`. Its local service reports per-component differences and cannot apply changes from the browser. Later MCP reviews must edit only its proposal until explicit approval.
- `DesignReview.vue` compares every registered proposal with its own reference, shows the pending count and filter, and displays only the selected component's details and actions. In manual mode, the CTA browser action becomes available only after Codex checks Figma through MCP and prepares the proposal; the service verifies the prepared code and review record, then backs up and reruns checks before applying. ProductLogo and KeyHighlights remain read-only. The automatic Figma service remains available when configured separately. Neither path publishes to production.

The Acronis Cyber font is not included in this repository. ProductLogo uses a temporary Helvetica Neue / Arial fallback. This is not an exact visual reproduction; replace it with licensed Acronis Cyber Light and Bold files when supplied.

KeyHighlights also needs Acronis Cyber Bold and Regular for exact typography. Its temporary Arial fallback can change line breaks. The Metrics motion uses the documentation's visibility and replay rules; the 900 ms count and 120 ms desktop stagger are implementation timings because the documentation supplies no fixed durations. Metrics has no charts.
